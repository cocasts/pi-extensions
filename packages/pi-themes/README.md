# @cocasts/pi-themes

Curated color themes for the [pi coding agent](https://pi.dev).

## Included themes

- `nord` — a dark theme based on the classic Nord palette.

## Installation

```bash
pi install npm:@cocasts/pi-themes
```

If pi is already running, use `/reload` after installation. Open `/settings`
and select `nord` as the active theme.

## Development

From the monorepo root:

```bash
bun install
bun run verify
```

To load the local package in pi:

```bash
pi install ./packages/pi-themes
```
